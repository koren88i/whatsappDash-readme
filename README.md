# WhatsApp Activity Dashboard

A personal, local-first dashboard for understanding WhatsApp activity. It summarizes message counts, time patterns, conversation sessions, response times, group participation, and voice-note duration. It also shows when collection was offline so gaps in coverage are visible.

The application runs on the owner's computer with Docker Compose and SQLite. It uses a linked WhatsApp Web session to collect activity and does not send WhatsApp messages.

This repository contains only this public overview. The application source, configuration, development history, and personal data are kept in a separate private repository or on the owner's computer. This repository is not a runnable distribution.
